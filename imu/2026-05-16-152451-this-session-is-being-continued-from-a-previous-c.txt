> 串口接收消息是什么内容                                                        

● 串口接收有两种格式：

  1. 单字符命令：

  ┌────────┬──────────────────────┐
  │  字符  │         功能         │
  ├────────┼──────────────────────┤
  │ s 或 S │ 停止电机             │
  ├────────┼──────────────────────┤
  │ ?      │ 显示当前参数         │
  ├────────┼──────────────────────┤
  │ t      │ 启动PID (自动设目标) │
  ├────────┼──────────────────────┤
  │ T      │ 停止PID              │
  ├────────┼──────────────────────┤
  │ +      │ 手动增加PWM 200      │
  ├────────┼──────────────────────┤
  │ -      │ 手动减少PWM 200      │
  ├────────┼──────────────────────┤
  │ 1      │ 目标150 (低速)       │
  ├────────┼──────────────────────┤
  │ 2      │ 目标200 (正常)       │
  ├────────┼──────────────────────┤
  │ 3      │ 目标250 (快速)       │
  ├────────┼──────────────────────┤
  │ 4      │ 目标300 (高速)       │
  └────────┴──────────────────────┘

  2. SET指令 (LLM-PID-Tuner用)：
  SET P:10.0 I:0.8 D:0.4

  3. STATUS指令：
  STATUS
  自动启动PID，目标250脉冲/100ms

  ---
  示例：
  # 设置PID参数
  SET P:12.0 I:1.0 D:0.5

  # 查询状态
  ?

  # 停止
  s

● 串口接收数据格式：

  单字符命令：
  s    # 停止
  ?    # 查询
  t    # 启动PID
  T    # 停止PID
  +    # PWM+200
  -    # PWM-200
  1    # 目标150
  2    # 目标200
  3    # 目标250
  4    # 目标300

  SET指令 (LLM-PID-Tuner)：
  SET P:10.0 I:0.8 D:0.4

  STATUS指令：
  STATUS

  ---
  发送示例 (串口助手)：
  s\r\n           # 停止
  SET P:12.0 I:1.0 D:0.5\r\n   # 改参数
  STATUS\r\n      # 启动

● 芯片串口发送的数据：

  1. 初始化信息：
  === Motor PID (载人版本) ===
  FF_GAIN=12 Kp=10 Ki=0.8 Kd=0.4
  +/-:duty  s:stop  ?:show
  t:start PID  T:stop PID
  1-4:target 150/200/250/300

  2. 命令响应：
  # PID: P=12.00 I=1.00 D=0.50   # SET命令回复
  PID ON Tgt=250                   # t命令
  PID OFF                          # T命令
  D=200                            # +/-命令
  Tgt=150                          # 1-4命令
  STOP                             # s命令

  3. PID运行状态 (每100ms)：
  tgt=250(0.23m/s) spd=248(0.23m/s 0.8km/h) err=2 pwm=3200

  4. CSV数据 (LLM-PID-Tuner用)：
  100,250.0,248.0,3200.0,2.0,10.00,0.80,0.40
  格式：时间戳,设定值,实际值,PWM,误差,Kp,Ki,Kd
